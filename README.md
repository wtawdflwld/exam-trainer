# 過去問ノート — 個人用・オフライン学習PWA

Windows PCで問題を手動登録し、iPhoneで学習するための**動作する初期版**です。

- 四択回答 / 正誤判定 / 解説表示 / 回路図などの画像表示
- 資格・年度・試験回・分野・細分野での絞り込み
- ランダム出題 / 全問・10問・20問
- 要復習（直近の回答が不正解）とお気に入り
- IndexedDBへの解答履歴保存・正解率表示
- JSONバックアップと復元
- オフライン用キャッシュ

**初期収録は12問のオリジナル例題です。実際の第一種・第二種電気工事士の過去問ではありません。**

## 1. Windows PCで最初の動作確認をする

1. ZIPファイルを右クリックして「すべて展開」。展開後のフォルダー名は `exam_trainer_pwa` です。
2. [Python](https://www.python.org/downloads/) がインストールされていれば、エクスプローラーで `exam_trainer_pwa` を開き、アドレスバーへ `cmd` と入力してEnter。
3. 表示されたコマンドプロンプトで次を実行。

   ```powershell
   py -m http.server 8000
   ```

   `py` が見つからなければ `python -m http.server 8000` を試してください。未導入の場合はPythonをインストールするか、VS Codeのローカルサーバー機能を利用してください。

4. Windowsのブラウザで `http://localhost:8000/` にアクセス。
5. 設問を解き、間違い復習・お気に入り・バックアップを確認してください。

**`index.html` を直接ダブルクリックして開く `file://` 方式では、CSV読み込みやオフライン機能が動作しません。** 必ず localhost または HTTPS でアクセスしてください。

## 2. 問題をExcelで手動登録する

- `questions_edit_template.xlsx` をExcelで開くと、入力しやすい表と説明シートがあります。
- **「問題登録」シートの1行目を変更しないでください。** それ以降に1問ずつ入力します。
- 保存時は**「CSV UTF-8（コンマ区切り）（*.csv）」**を選び、ファイル名を `questions.csv` にします。
- 保存したCSVをこのフォルダーの `questions.csv` と置き換えます。必要に応じて、あらかじめオリジナルCSVのコピーを取ってください。
- 本番データに差し替える際は、初期のサンプル12問を削除するか別ファイルに退避させてください。
- ExcelのCSV出力では**現在のシートだけがCSV化**されます。**「問題登録」**を選んでから保存してください。

### CSV列の説明

| 列 | 内容 | 入力例 | 必須 |
|---|---|---|---|
| id | 問題固有のID。一度決めたら変更しない | E1-R03-AM-01 | はい |
| qualification | 資格名 | 第一種電気工事士 | はい |
| year | 年度 | 令和3年度 | 任意 |
| session | 試験回 | 午前 | 任意 |
| category | 分野 | 電気理論 | はい |
| topic | 細分野 | コイルのエネルギー | 任意 |
| question | 問題文 | コイルに蓄えられるエネルギーは… | はい |
| choice1 ～ choice4 | 選択肢4つ | 0.5 J | はい |
| answer | 正解の番号 | 3（1〜4） | はい |
| explanation | 解説 | W=(1/2)LI² で… | 任意 |
| image | 図の相対パス | images/circuit01.png | 任意 |

**注意**: `id` は全問で重複禁止です。別資格・別年度でも固有にします。IDを変更すると同じ問題として過去の解答履歴を引き継げなくなります。

問題文にコンマ・改行が含まれても、Excelからの正規のCSV書き出しなら処理できます。WindowsのExcelでは文字化け回避のために必ず「CSV UTF-8」を選んでください。

### 図・回路図の追加

画像を `images` フォルダーに入れ、`image` 列へ `images/filename.png` と入力します。PNG、JPEG、WEBP、GIF、SVGに対応します。画像のフォルダーごとGitHubにアップロードしてください。初回のオフライン準備時に登録済みの画像も保存します。

## 3. GitHub Pagesで公開する（無料）

1. [GitHub](https://github.com/) のアカウントを作成します。
2. 画面の `New repository` で、例として `exam-trainer` という**Public**の新規リポジトリを作成します。
3. `Add file` → `Upload files` で、このZIPを展開したフォルダーの**中身**をアップロードします。少なくとも以下が必要です。
   - `index.html`
   - `style.css`
   - `app.js`
   - `sw.js`
   - `questions.csv`
   - `manifest.webmanifest`
   - `icon-192.png`, `icon-512.png`
   - `images/` 内の画像ファイル
   - `.nojekyll`（任意）
4. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` を選び、`main` と `/(root)` を指定して保存。
5. 公開が完了すると、通常 `https://GitHubユーザー名.github.io/exam-trainer/` というURLで開けます。リポジトリ名によってURLは変わります。
6. 公開URLにアクセスし、アプリが動作することを確認します。

**GitHub Pagesのサイトはインターネット上に公開されます。** 個人用であっても、アプリのコード・CSV・画像を非公開にする仕組みではありません。自分の学習履歴はGitHubにアップロードされず端末に保存されます。

## 4. iPhoneのホーム画面に追加する

1. iPhoneが**インターネット接続中**の状態で、公開URLを**Safari**で開きます。
2. 共有ボタン（表示位置はiOSの構成により異なります）から `ホーム画面に追加` を選びます。
3. `ウェブアプリとして開く` が表示される場合は有効にして `追加` を選びます。
4. iPhoneのホーム画面にできた **「過去問ノート」** のアイコンから起動します。
5. **必ずホーム画面のアプリ側で** `オフライン用データを準備` を押し、「準備完了」の表示を確認します。Safari画面とホーム画面アプリとで保存領域が分かれることがあるため、Safari側で準備しただけで完了と判断しないでください。
6. 機内モードに切り替え、**ホーム画面のアプリを終了→起動**して問題・画像・履歴が使えるか確認します。

iPhoneの空き容量不足、ブラウザのデータ消去、OSの管理などでキャッシュや学習履歴が失われる可能性があります。定期的にバックアップしてください。オフライン準備が終わるまでは通信接続が必要です。

## 5. 問題を追加・修正するとき

1. Windowsの `questions_edit_template.xlsx` を編集します。
2. `questions.csv` として書き出し、GitHubリポジトリの `questions.csv` を**更新**します。新規画像があれば `images` フォルダーへ追加します。
3. iPhoneをオンラインに戻します。
4. ホーム画面のアプリで「最新版を読み込み」を押します。
5. 続けて「オフライン用データを準備」を押し、問題数・画像数を確認します。
6. 再び機内モードで、新しい問題や画像を確認します。

HTML/CSS/JavaScriptなど**アプリ本体のコードを更新**した場合は、`sw.js` 冒頭の `CACHE_VERSION` を `exam-trainer-shell-v2` などへ更新し、再公開してください。CSVだけ変更した場合は原則としてバージョン変更不要です。

## 6. バックアップについて

- 「履歴をバックアップ」からJSONファイルを書き出します。iPhoneでは「ファイル」アプリなどに保存してください。
- 復元する場合は「履歴を復元」からJSONを選択します。**復元すると既存の履歴を置き換えます。**
- バックアップのJSONは解答回数・正答数・要復習・お気に入りを保持し、問題文自体は含みません。問題IDとCSVの整合性を維持してください。
- この初期版では、WindowsとiPhoneの履歴は自動同期しません。手動バックアップ・復元で移動できます。

## 7. 実装の前提・制限

- 4択・1つの正解という形式に対応しています（複数選択や自由記述には未対応）。
- 「要復習」は**最後に解いたときに不正解だった問題**です。正解すると要復習リストから外れます。累計の誤答履歴は正解率に反映されます。
- データ保存にはIndexedDB、オフライン動作にはService Worker + Cache APIを使用します。
- 問題文や選択肢はテキストとして表示します。数式はUnicode等で書くか、図として画像を登録してください（数式レンダラは未搭載）。
- 大量の画像を追加する場合はiPhoneの保存容量を確認してください。
- Webアプリの配信先はGitHub Pagesを想定しています。ログイン機能・外部DB・有料APIは利用しません。
- 試験問題を手入力するときは、公式サイトの利用条件、出典の明記、第三者の解説文・図版の著作権を確認してください。
