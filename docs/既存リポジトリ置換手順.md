# 既存リポジトリの試作版を本番版へ置換する

対象：wtawdflwld/exam-trainer、公開先：https://wtawdflwld.github.io/exam-trainer/

現在はmainブランチのルートをPages公開しています。この一式はその設定のまま公開できます。v2フォルダーには入れず、READMEとindex.htmlがリポジトリ直下になるように配置します。

## Gitを使う場合

1. この準備済みフォルダーを使い、変更一覧を確認します。旧版を除去し本番版一式に差し替えたローカルcommitを用意しています。
2. 対象リポジトリへ書き込めるGitHubアカウントで認証します。
3. `git push origin main` を実行します。force pushは不要です。リモートに追加変更があれば止めて差分を確認します。
4. Pagesの公開成功を待ち、公開URLで新しい画面を確認します。

## GitHubのブラウザー画面で行う場合

1. 現在のmainの内容を保管し、必要なら旧アプリから学習JSONをバックアップします。
2. ルートの旧 `app.js`, `style.css`, `questions.csv`, `questions_edit_template.xlsx`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` と `images/ohm.svg` を削除します。`index.html`, `sw.js`, `README.md` は新しい同名ファイルで置き換えます。
3. 置換用ZIPを展開し、中身をリポジトリのルートへアップロードします。ZIPファイル自体や外側のフォルダーをアップロードしません。`.nojekyll` と `.gitignore` も含めます。
4. 公開設定はDeploy from a branch、main、/(root)を維持します。
5. Pagesの公開成功後、オンラインのSafariで公開URLを開いて本番版を確認します。確認後にホーム画面アプリを開き直します。

旧版ファイルの除去と新ファイルの登録の間に、短時間サイトが使えなくなる場合があります。Gitの1commitでの置換なら一度に反映できます。

本番版は教材0問から始まります。旧学習DBやサイトデータを一括削除しないでください。旧バックアップの本版への自動移行はありません。Gitの過去commitは履歴として残します。
